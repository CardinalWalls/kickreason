# The view layers — one node, re-read many ways

The same researched node is re-read for a different reader each time ("produce once, sell many"). Each layer
is a real profession with a real system and a real grade.

| Layer | The reader | What the node gives them | Graded by |
|---|---|---|---|
| **ODDS / calibration** | bettor / quant | calibrated probability, de-vigged line, CLV | Brier · CLV |
| **STATS** | analyst / club | xG, shots, possession, set-pieces (sourced) | provider calibration |
| **NARRATIVE** | media / fan | the storyline, both cases, named sources | (engagement; we add a grade) |
| **MAGIC-MOMENT** | social / broadcast | the goal/scorer/minute/xG, the turning point | event truth |
| **TRAFFIC** *(new 5th)* | growth / creator | the moment→engagement spike, share-cards | CTR / reach / virality |

Plus adjacent B2B layers the same trace can serve (later): **recruitment** (signing-value/success),
**integrity** (suspicious-market signal), **calibration/trust** (the published track record — the wedge no
incumbent ships).

**Through-line:** every layer carries a published, self-graded number. We are NOT a bet demo — betting is one
of several domains served by one trace. The deepest shared want across all readers: *a receipt that proves
who was right.*
